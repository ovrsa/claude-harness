# Solution Evaluation Rules

## 目的

図を描いて終わり、計画を書いて終わり、にならないようにする。

## 評価で見ること

- 何が実際に変わったか
- 待ち時間や手戻りは減ったか
- 人が残す判断は適切に減ったか
- system of record は明確になったか
- KPI は改善したか

## 最低限の観点

- expected outcome
- actual outcome
- remaining friction
- new risks
- next backlog items

## ルール

- Phase 1 で success metrics を決めずに評価へ進まない
- 改善後図と実運用の差を放置しない
- 新しい例外が増えたら、改善後図を見直す
