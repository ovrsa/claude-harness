# Playwright Verification Rules

## 目的

ローカルで図を開き、第三者に見せられる品質かを確認する。

## 対象

- Draw.io から出力した SVG または PNG
- Structurizr から確認できるローカル画面

## Preconditions

- Draw.io は人手で最終配置を確認済みである
- スイムレーンは `現状図` と `改善後図` を export 済みである
- Structurizr は `Context` と `Container`、必要なら `Component` が開ける状態である
- Playwright が無い場合は、人手スクリーンショット確認へ戻してよい

## Draw.io review first

Playwright で確認する前に、Draw.io 上で次を人が確認する。

- 横軸（列）の担当・システム見出しが読める
- 縦軸（行）のフェーズ見出しが読める
- 主経路の矢印がセル本文の番号と対応している
- 矢印ラベルが他要素に被って読めなくなっていないか（`labelBackgroundColor` が効いているか）
- タスクボックスがマスを完全に埋めて矢印と衝突していないか
- 空きマスが大きな灰色塗りではなく、小さい灰色ラベルになっているか
- 注記がセル本文や矢印を隠していない
- 通常フローが上から下に追える
- 現状図と改善後図でフェーズ粒度が揃っている

## Pass Criteria

- 主要ラベルが切れていない
- 主要ノードが重なっていない
- 通常フローを目で追える
- Context と Container の境界が視認できる
- 現状図と改善後図の差分が読める

## Minimal Execution Flow

### Swimlane

1. Draw.io から `現状図` と `改善後図` を SVG または PNG で export する
2. `1440x900` で全体を確認する
3. `1280x800` でラベル崩れを確認する
4. `現状図` と `改善後図` のスクリーンショットを残す

### C4

1. Structurizr Local で sample または対象 workspace を起動する
2. `Context` を開いてスクリーンショットを残す
3. `Container` を開いてスクリーンショットを残す
4. 必要なら `Component` を開いてスクリーンショットを残す

### Required Evidence

- 現状スイムレーン
- 改善後スイムレーン
- C4 Context
- C4 Container

## 確認観点

- ラベル切れ
- テキスト重なり
- 図形の重なり
- 矢印の交差過多
- 重要ノードの視認性
- viewport 差分

## 最低限の確認

- デスクトップ幅で全体確認
- 小さめの幅でラベル崩れ確認
- 現状スイムレーンと改善後スイムレーンを並べて確認
- C4 Context と Container を個別確認

推奨 viewport:

- `1440x900`
- `1280x800`

## 原則

- コンパイル成功で完了扱いにしない
- スクリーンショットを証跡として残す
- 問題があれば構造を直し、見た目だけでごまかさない

## 証跡

- スクリーンショット
- 必要なら簡単な所見メモ
- 修正前後の比較画像
