# Example KPI

## Business KPI

| metric | before | target | actual | notes |
| --- | --- | --- | --- | --- |
| Processing time | 2営業日 | 当日中 |  | 標準案件を短縮 |
| Waiting time | 承認待ちが半日〜1日 | 30分以内 |  | 例外だけ承認 |
| Rework count | 2回 | 0回 |  | Excel 再入力を廃止 |
| Double entry count | 1案件あたり2系統 | 1系統 |  | 正本統一 |

## Delivery KPI

| metric | before | target | actual | notes |
| --- | --- | --- | --- | --- |
| Deployment Frequency | 月1回 | 週1回以上 |  | 改善サイクルを短縮 |
| Lead Time for Changes | 2週間 | 3日以内 |  | 変更反映の速度 |
| Change Failure Rate | 未計測 | 15%以下 |  | 最低限の管理値 |
| Time to Restore Service | 未計測 | 4時間以内 |  | 運用復旧指標 |
