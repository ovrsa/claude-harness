# Post-Commit Asset Capture

Use this skill after a task is implemented and committed.

## Classification

For each lesson learned, choose one:

1. task-specific knowledge
2. project docs update
3. reusable workflow candidate

## Promote to a skill only if all are true

- repeated at least 3 times
- stable procedure
- clear inputs and outputs
- costly to re-explain every time
